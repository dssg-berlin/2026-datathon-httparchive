# HTTP Archive Datathon

This repository contains the **PHP-to-Shell vulnerability and HTTP Archive
insights** workstream from the DSSG Berlin Datathon. The analysis, datasets,
notebooks, SQL, visualization scripts, notes, and figures are organized in
[`php2shell/`](./php2shell/).

Start with the [PHP2Shell project README](./php2shell/README.md) for findings,
data provenance, and instructions for running the analysis.

The workstream includes contributions from Elena and Benjamin Senst.
